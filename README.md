# 🐧 دوره صفر تا صد لینوکس — از نصب و دسکتاپ تا ترمینال و اسکریپت‌نویسی حرفه‌ای

> 🤖 **تولید شده توسط هوش مصنوعی:** این دوره به‌طور کامل توسط مدل **GLM-5.3-Flash** تولید و تدوین شده است.
> **نسخه دوره:** جامع و کاربردی — ویژه توسعه‌دهندگان، مدیران سیستم و کاربران علاقه‌مند به دنیای متن‌باز
> **پیش‌نیاز:** هیچ! از صفر مطلق شروع می‌شود و بدون استرس شما را تا کار با سرورها و اتوماسیون همراهی می‌کند.

---

## 🎯 چرا لینوکس؟

بیش از ۹۰٪ وب‌سرورهای دنیا، ابررایانه‌ها، داکر، گوشی‌های اندرویدی و سیستم‌های ابری روی لینوکس اجرا می‌شوند. تسلط بر لینوکس نه یک گزینه، بلکه یک الزام برای هر برنامه‌نویس و مهندس زیرساخت است. در این دوره یاد می‌گیرید که چگونه بدون ترس از صفحه سیاه ترمینال، سیستم‌عامل خود را مدیریت کنید.

| [فصل ۳](./content/ch03.md) | دسکتاپ لینوکس؛ استفاده روزمره بدون ترمینال | محیط‌های گرافیکی (GNOME, KDE)، مدیریت فایل‌ها، کلیدهای میانبر و ابزارهای پیش‌فرض |

| [فصل ۶](./content/ch06.md) | نقشه جزیره؛ درخت فایل‌سیستم لینوکس | آناتومی دایرکتوری‌ها (`/etc`, `/var`, `/home`, `/bin`, `/usr`) و مفهوم همه‌چیز فایل است |
| [فصل ۷](./content/ch07.md) | متن؛ خواندن، جست‌وجو و ویرایش | ابزارهای مشاهده و فیلتر (`cat`, `less`, `grep`, `head`, `tail`) و ویرایشگر nano و مقدماتی vim |
| [فصل ۸](./content/ch08.md) | دسترسی‌ها؛ قفل‌ها و کلیدها | مجوزهای خواندن/نوشتن/اجرا (`chmod`, `chown`)، سطوح کاربری و مدیریت دستور `sudo` |
| [فصل ۹](./content/ch09.md) | نصب نرم‌افزار؛ مخازن و مدیریت بسته | کار با مدیر بسته‌ها (`apt`, `dnf`)، ساختار ریپازیتوری‌ها، اسنپ (Snap) و فلت‌پک (Flatpak) |
| [فصل ۱۰](./content/ch10.md) | پردازش‌ها و خدمات سیستم | مانیتورینگ منابع (`top`, `htop`, `ps`)، مدیریت سرویس‌ها با `systemctl` و kill کردن پروسه‌ها |
| [فصل ۱۱](./content/ch11.md) | شبکه و دسترسی از راه دور | پیکربندی IP، دستورات پینگ و تست پورت، اتصال امن SSH و انتقال فایل با SCP/Rsync |
| [فصل ۱۲](./content/ch12.md) | بش اسکریپت‌نویسی؛ سیستم را اتوماتیک کنید | ش‌بنگ (`#!/bin/bash`)، متغیرها، شرط‌ها، حلقه‌ها و نوشتن تسک‌های زمان‌بندی‌شده با Cron |
| [فصل ۱۳](./content/ch13.md) | مسیر برنامه‌نویس؛ ابزارهای حرفه‌ای روی لینوکس | نصب گیت، Node.js، پایتون، داکر، تنظیم کلیدهای SSH و متغیرهای محیطی (`.bashrc` / `.zshrc`) |
| [فصل ۱۴](./content/ch14.md) | چیت‌شیت، گلاساری و نقشه راه ۹۰ روزه | واژه‌نامه اصطلاحات، جدول پرکاربردترین دستورات، کدهای خطای رایج و ادامه یادگیری |
