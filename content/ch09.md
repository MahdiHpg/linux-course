## ۹-۱ | ایده بزرگ: فروشگاه رسمی سیستم

در ویندوز، نرم‌افزار را از سایت‌های مختلف دانلود و نصاب‌های مختلف را اجرا می‌کنید. در لینوکس، توزیع شما یک **مخزن (Repository)** دارد: بایگانی رسمی هزاران نرم‌افزار تست‌شده که هر بسته با **امضای دیجیتال** محافظت می‌شود. مدیر بسته (apt) سه کار می‌کند: فهرست مخازن را می‌خواند، بسته‌ی درست را با همه‌ی **وابستگی‌هایش** (کتابخانه‌های لازم) نصب می‌کند و آپدیت امنیتی همه را یکجا می‌دهد. کروم، VLC، GIMP، VS Code، پایتون — همه از همان یک در.

::: term
$ sudo apt update               # فهرست نسخه‌های موجود را تازه کن (نصب نمی‌کند!)
$ sudo apt upgrade -y           # همه بسته‌های نصب‌شده را ارتقا بده
$ sudo apt install vlc          # نصب VLC (وابستگی‌ها خودکار)
$ sudo apt install vlc gimp git # نصب چندتایی در یک خط
$ apt search python3-jupyter    # جستجو در مخازن
$ apt show vlc                  # مشخصات و توضیح بسته
$ sudo apt remove vlc           # حذف (تنظیمات می‌ماند)
$ sudo apt purge vlc            # حذف کامل با تنظیمات
$ sudo apt autoremove           # پاکسازی وابستگی‌های یتیم
:::

مهم‌ترین سؤال تازه‌کارها: فرق `update` و `upgrade`؟ `update` فقط **فهرست** را تازه می‌کند (می‌پرسد «چی جدید هست؟») و `upgrade` خود نرم‌افزارها را ارتقا می‌دهد. به همین دلیل همیشه اول update بعد upgrade — و این دو را می‌توان در یک خط زنجیر کرد: `sudo apt update && sudo apt upgrade -y`.

## ۹-۲ | فایل `.deb` و مخازن اضافی؛ با احتیاط

گاهی نرم‌افزاری در مخازن نیست (مثل کروم یا برخی ابزارهای شرکت‌ها) و سایت سازنده، فایل `.deb` می‌دهد. نصبش با dpkg است و اگر وابستگی کم داشت، apt خودش را با یک دستور کامل می‌کند:

::: term
$ sudo dpkg -i code.deb         # نصب بسته محلی
$ sudo apt install -f           # درست‌کردن وابستگی‌های ناقص
:::

برخی سایت‌ها «مخزن اضافی» یا PPA می‌دهند تا نسخه‌های جدیدتر بگیرید: با `sudo add-apt-repository ppa:owner/name` اضافه می‌شود. قانون ایمنی: PPA و مخزن ناشناس یعنی «نرم‌افزار از فروشنده ناشناس» — فقط از منابع معتبر سازنده و تا وقتی آن نسخه را واقعاً لازم دارید. با `apt policy نام‌بسته` همیشه می‌بینید هر نسخه از کدام مخزن آمده.

::: tip | دسکتاپ مدرن: App Center
در اوبونتوی ۲۶.۰۴ همان کارهای بالا یک رابط گرافیکی هم دارد: **App Center**. جست‌وجو و نصب با کلیک، آپدیت‌ها هم همان‌جا. پس کدام بهتر است؟ برای دیدن «چه چیزی دارم و از کجا» ترمینال صادق‌تر و سریع‌تر است؛ برای گشتن و کشف، App Center لذت‌بخش‌تر. حرفه‌ای‌ها هر دو را با هم استفاده می‌کنند.
:::

## ۹-۳ | دنیای چندتوزیعی؛ یک جدول برای همه

همه‌ی مفاهیم این فصل در هر توزیعی هست؛ فقط اسم‌ها فرق می‌کند. این جدول را وقتی به سرور شرکت یا توزیع دیگری رفتید، مرجع قرار دهید:

| کار | اوبونتو/دبیان (apt) | فدورا/RHEL (dnf) | آرچ (pacman) |
| --- | --- | --- | --- |
| تازه‌کردن فهرست | apt update | dnf check-update | pacman -Sy |
| نصب | apt install vlc | dnf install vlc | pacman -S vlc |
| حذف | apt remove vlc | dnf remove vlc | pacman -R vlc |
| ارتقای همه | apt upgrade | dnf upgrade | pacman -Syu |
| جست‌وجو | apt search vlc | dnf search vlc | pacman -Ss vlc |
| فایل بسته | `.deb` | `.rpm` | `.pkg.tar.zst` |

## ۹-۴ | snap و flatpak؛ بسته‌های جهانی

دو پروژه‌ی جدیدتر مشکل «این اپ در مخزن نیست یا قدیمی است» را حل می‌کنند: **snap** (از کاننICAL، پیش‌فرض اوبونتو — App Center عمدتاً snap نصب می‌کند) و **flatpak** (جامعه‌ای، محبوب در فدورا). بسته‌هایشان «همه‌چیز‌شامل» هستند: با وابستگی‌های خودشان، روی هر توزیعی اجرا می‌شوند و آپدیت خودکار دارند. بهای این استقلال: حجم بیشتر و اولین اجرای کمی کندتر. قاعده انتخاب: اپ اصلی سیستم را از apt بگیرید؛ اپ‌های دسکتاپی که نسخه‌ی تازه‌شان را می‌خواهید (مثل برخی اپ‌های گرافیکی) از snap/flatpak:

::: term
$ snap list                      # چه snapهایی دارید؟
$ sudo snap install spotify      # مثال snap
$ flatpak search obs             # جستجوی flatpak (اگر فعال باشد)
$ flatpak install flathub com.obsproject.Studio
:::

::: exercise | تمرین فصل ۹
(۱) `apt list --installed | wc -l` بزنید — چند بسته نصب دارید؟ (شاید صدها؛ سیستم لینوکسی از صدها قطعه ساخته شده!) (۲) با `apt search` ابزاری برای ویرایش عکس پیدا و با `apt show` مشخصاتش را بخوانید. (۳) آن را نصب، اجرا و سپس با `purge` و `autoremove` کامل پاک کنید. (۴) `snap list` را اجرا کنید و ببینید کدام اپ‌های سیستم‌تان snap هستند.
:::

::: key | جمع‌بندی فصل ۹
- مخزن = فروشگاه رسمی با امضای دیجیتال؛ apt نصب + وابستگی‌ها + آپدیت امنیتی را یکجا حل می‌کند.
- update فهرست را تازه می‌کند، upgrade خود نرم‌افزار را؛ هفتگی: `apt update && apt upgrade -y`.
- `.deb` با dpkg نصب می‌شود و `apt install -f` وابستگی را کامل می‌کند؛ PPA فقط از منبع معتبر.
- جدول معادل dnf/pacman را نگه دارید؛ snap/flatpak برای اپ‌های تازه‌ی دسکتاپی.
:::
