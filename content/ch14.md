## ۱۴-۱ | چیت‌شیت ۱: دستورهای روزمره

| دستور | کار | دستور | کار |
| --- | --- | --- | --- |
| `pwd` | کجاییم؟ | `ls -lha` | فهرست کامل و خوانا |
| `cd ~` / `cd -` | خانه / برگشت | `cd ..` | یک پله بالا |
| `mkdir -p a/b` | ساخت زنجیره‌ای | `touch f` | ساخت فایل |
| `cp -r a b` | کپی پوشه | `mv a b` | انتقال/تغییر نام |
| `rm -i f` | حذف با پرسش | `find . -name "*.log"` | جست‌وجوی فایل |
| `df -h` / `du -sh` | فضای دیسک / پوشه | `ln -s src dst` | لینک نمادین |
| `cat` / `less` | خواندن کوتاه / بلند | `head -20` / `tail -f` | ابتدا / انتهای زنده |
| `grep -rn "متن" .` | جست‌وجوی متن | `history` | تاریخچه دستورها |
| `man cmd` / `cmd --help` | مستندات | `Ctrl+C` / `Ctrl+R` | قطع / جست‌وجوی تاریخچه |

## ۱۴-۲ | چیت‌شیت ۲: سیستم، شبکه و اسکریپت

| دستور | کار |
| --- | --- |
| `sudo apt update && sudo apt upgrade -y` | آپدیت کامل سیستم |
| `apt search/show/install/remove` | چرخه‌ی کامل بسته |
| `ps aux` + `kill PID` | دیدن و بستن پردازش |
| `htop` | پایش زنده زیبا |
| `systemctl status/start/enable svc` | کنترل سرویس |
| `journalctl -u svc -e` / `-p err -b` | لاگ سرویس / خطاهای بوت |
| `ip a` + `ping -c 4 host` | آدرس و تست اتصال |
| `ssh user@ip` + `scp f user@ip:~/` | راه دور و انتقال فایل |
| `ssh-keygen -t ed25519` | ساخت کلید امن |
| `ufw allow ssh && ufw enable` | فایروال حداقلی |
| `tar -czf out.tar.gz dir/` | فشرده‌سازی بکاپ |
| `bash -n script.sh` | تست نحوی اسکریپت |

**الگوی ۱۰ قدمی عیب‌یابی:** ۱. پیام خطا را کامل بخوانید ← ۲. چه چیزی تغییر کرد؟ ← ۳. `htop` (منابع) ← ۴. `df -h` (دیسک پر؟) ← ۵. `ping` (شبکه؟) ← ۶. لاگ سرویس: `journalctl -u x -e` ← ۷. خطاهای بوت: `journalctl -p err -b` ← ۸. تنظیمات تازه را برگردانید ← ۹. پیام خطا را جست‌وجو کنید ← ۱۰. در آخر: ری‌استارت (واقعاً ربع مشکل‌ها را حل می‌کند!).

## ۱۴-۳ | گلاساری؛ واژه‌نامه فارسی–انگلیسی

| فارسی | معادل | یک خط توضیح |
| --- | --- | --- |
| کرنل | Kernel | هسته سیستم‌عامل؛ مدیر منابع سخت‌افزار |
| توزیع | Distribution | بسته‌ی کامل: کرنل + ابزارها + مدیر بسته |
| پوسته | Shell | مفسر دستورها (bash، zsh) |
| ترمینال | Terminal | پنجره‌ی گفت‌وگو با پوسته |
| پرامپت | Prompt | خط آماده‌باش؛ مثلا `user@host:~$` |
| مسیر مطلق/نسبی | Absolute/Relative | از `/` / از مکان فعلی |
| مخفی | Hidden | فایل نقطه‌دار مثل `.bashrc` |
| مجوز | Permission | rwx برای مالکار/گروه/بقیه |
| sudo | superuser do | اجرای یک دستور با دسترسی مدیر |
| ریشه | root | کاربر همه‌قدت‌دار سیستم |
| مدیر بسته | Package Manager | apt/dnf/pacman؛ نصب از مخازن |
| مخزن | Repository | بایگانی رسمی و امضاشده بسته‌ها |
| وابستگی | Dependency | کتابخانه‌های لازم یک نرم‌افزار |
| پردازش | Process | برنامه در حال اجرا با PID |
| سرویس/شیطانک | Service/Daemon | برنامه پس‌زمینه مدیریت‌شده با systemd |
| لوله | Pipe \| | ریختن خروجی یک دستور به دیگری |
| سوار کردن | Mount | اتصال دیسک/فلش به درخت فایل |
| لینک نمادین | Symlink | میان‌بر سطح فایل‌سیستم |
| محیط مجازی | venv | کتابخانه‌های ایزوله هر پروژه پایتون |
| کانتینر | Container | بسته‌ی اجرای یکسان برنامه (داکر) |
| پوسته اسکریپت | Shell Script | فایل متنِ دستورها برای اتوماسیون |
| فایروال | Firewall | کنترل درهای شبکه (ufw) |
| SSH | Secure Shell | ترمینال امن از راه دور |
| ترمینال‌امولاتور | Terminal Emulator | برنامه‌ی پنجره‌ی ترمینال (گنوم‌ترمینال) |
| دسکتاپ | Desktop Environment | پوسته گرافیکی (گنوم/KDE/XFCE) |

## ۱۴-۴ | نقشه راه ۹۰ روزه

| هفته | تمرکز | تمرین عملی |
| --- | --- | --- |
| ۱–۲ | فصل ۱–۳: نصب و دسکتاپ | VM آماده، فارسی‌سازی، یک هفته فقط با دسکتاپ لینوکس کار کنید |
| ۳–۴ | فصل ۴–۵: ترمینال و فایل‌ها | روزی ۱۵ دقیقه ترمینال؛ ماوس را عمداً کنار بگذارید |
| ۵–۶ | فصل ۶–۷: فایل‌سیستم و متن | سه عیب‌یابی لاگ واقعی؛ ۱۰ بار grep در /etc و /var/log |
| ۷–۸ | فصل ۸–۹: دسترسی و بسته‌ها | کل نصب یک هفته فقط با apt؛ جدول مجوزها را از حفظ بنویسید |
| ۹–۱۰ | فصل ۱۰–۱۱: سیستم و شبکه | یک VM دوم راه بیندازید و ssh+scp+ufw را کامل تمرین کنید |
| ۱۱–۱۲ | فصل ۱۲: اسکریپت | سه اسکریپت واقعی برای نیاز خودتان بنویسید و در ~/bin بگذارید |
| ۱۳ | فصل ۱۳: توسعه | پروژه با git+venv یا nvm؛ push به گیت‌هاب؛ داکر nginx |
| ۱۴ | فصل ۱۴: مرور | خودارزیابی، بازخوانی دفترچه، تکرار چیت‌شیت‌ها |
| پس از ۹۰ روز | مسیر عمیق | bash پیشرفته، systemd واحد نگارش، داکر compose، و یک سرور واقعی (ارزان‌ترین VPS) |

**هماهنگ با نسخه‌ها:** اوبونتوی شما ۲۶.۰۴ LTS است و تا ۲۰۳۱ آپدیت امنیتی دارد؛ هفته‌ای یک‌بار `apt update && apt upgrade` و هر دو سال، ارتقای LTS بعدی (با `sudo do-release-upgrade` بعد از خروج نسخه‌ی جدید و گرفتن بکاپ) — تمرین این ارتقا را اول در VM انجام دهید.

## ۱۴-۵ | خودارزیابی نهایی

اگر به ۸ مورد از این ۱۰ پرسش پاسخ روان بدهید، «آماده‌ی کار» هستید: ۱. فرق کرنل و توزیع؟ ۲. سه کار اول بعد از نصب؟ ۳. فرق update و upgrade در apt؟ ۴. مسیر تنظیمات و لاگ‌ها؟ ۵. مجوز ۷۵۴ را باز کنید؛ مالکار چه کارهایی می‌کند؟ ۶. چطور پردازشِ هنگ‌کرده را می‌بندید؟ ۷. چرخه‌ی عیب‌یابی یک سرویس خاموش؟ ۸. چطور بدون رمز به سرور ssh می‌زنید؟ ۹. یک اسکریپت بکاپ با تاریخ بنویسید. ۱۰. فایروال حداقلی یک سرور شخصی؟

::: exercise | تمرین نهایی دوره
یک «روز کامل لینوکسی» بگذرانید: از صبح تا شب سیستم را با لینوکس اداره کنید — متنی بنویسید، فیلم ببینید، یک مشکل را خودتان عیب‌یابی کنید، یک اسکریپت کوچک برای خودتان بنویسید و در پایان روز، یک commit به «دفترچه یادگیری» خودتان در git بزنید. فردا هم تکرار کنید — این تک‌تمرین، ارزش کل دوره را آزاد می‌کند.
:::

::: key | پایان دوره
- چیت‌شیت‌ها را چاپ کنید؛ عیب‌یابی یک الگوی ده‌قدمی ثابت است، نه یک استعداد.
- گلاساری را در گفتار روزمره استفاده کنید؛ زبان حرفه‌ای، تفکر حرفه‌ای می‌سازد.
- برنامه ۹۰ روزه فقط با «روزانه» جواب می‌دهد؛ ۱۵ دقیقه در روز از ۳ ساعت آخر هفته بهتر است.
- و حرف آخر: ترمینال از امروز مال شماست. هر دستورِ امروز، فردا یک ابزار است. خوش آمدید به لینوکس!
:::
