## ۱۲-۱ | اولین اسکریپت

اسکریپت یعنی «فهرست دستورها در یک فایل». خط اولش **شی‌بنگ** است که می‌گوید «این فایل را با bash اجرا کن»:

::: term
$ nano ~/hello.sh
#!/bin/bash
# اسکریپت اول من — خط‌های با # کامنت‌اند
echo "سلام لینوکس! امروز: $(date +%A)"
$ chmod +x ~/hello.sh      # اجرایی کن (فصل ۸)
$ ~/hello.sh
سلام لینوکس! امروز: شنبه
:::

سه قدم همیشگی: بنویس، اجرایی کن (`chmod +x` فقط یک بار)، اجرا کن. چرا اسکریپت؟ چون ترتیب دستورها **حفظ می‌شود، مستند است و قابل تکرار** — هر کاری که دو بار انجام دادید، بار سوم باید اسکریپت باشد!

## ۱۲-۲ | متغیرها، ورودی و جایگزینی

::: term
#!/bin/bash
name="Mehdi"                 # متغیر: بدون فاصله دور از =
echo "سلام $name"            # خواندن با $
echo "نام اسکریپت: $0"       # نام خود اسکریپت
echo "اولین آرگومان: $1"     # ورودی هنگام اجرا: ./greet.sh Ali
read -p "اسمت چیه؟ " user    # پرسش زنده از کاربر
echo "خوش آمدی $user"
files=$(ls | wc -l)          # جایگزینی دستور: خروجی دستور در متغیر
echo "اینجا $files فایل داری"
:::

سه چیز تازه: آرگومان‌های اجرا با `$1` و `$2` می‌آیند (`./greet.sh Ali` یعنی `$1`=Ali)؛ `read -p` زنده می‌پرسد؛ و `$(دستور)` خروجی هر دستوری را می‌گیرد و جای خودش می‌گذارد — کلید ترکیب دستورها با هم.

## ۱۲-۳ | شرط و حلقه؛ وقتی سیستم تصمیم می‌گیرد

::: term
#!/bin/bash
# check.sh — سلامت یک فایل را بگو
if [ -f "$1" ]; then
    echo "پیدا شد؛ اندازه: $(du -h "$1" | cut -f1)"
elif [ -d "$1" ]; then
    echo "این یک پوشه است"
else
    echo "چنین چیزی نیست!"
fi
# حلقه: همه فایل‌های txt را بشمار و بگو
for f in *.txt; do
    echo "$f → $(wc -l < "$f") خط"
done
# while: تا وقتی دیسک زیر ۹۰٪ است، نگران نباش
df -h | while read line; do echo "$line"; done
:::

قاعده‌ی شرط bash: `if [ شرط ]` با فاصله‌های اجباری دور براکت؛ شرط‌های پرکاربرد: `-f` فایل است، `-d` پوشه است، `-z "$x"` خالی است، `"$a" = "$b"` برابر است، `-gt`/`-lt` بزرگ‌تر/کوچک‌تر عددی. و در همه‌جا، متغیرها را داخل گیومه بگذارید (`"$1"`) — واکسن استاندارد فایل‌هایی با فاصله در نام است. حلقه `for` روی لیست‌ها (خروجی دستورها هم می‌شود!) و `case` هم برای حالت‌های چندگانه هست.

## ۱۲-۴ | سه اسکریپت واقعی؛ جعبه‌ابزار شخصی شما

**۱) پشتیبان‌گیر با تاریخ:**

::: term
#!/bin/bash
# backup.sh — از پوشه پروژه‌ها، نسخه با تاریخ بساز
src="$HOME/projects"
dest="$HOME/backups"
mkdir -p "$dest"
tar -czf "$dest/projects-$(date +%Y%m%d-%H%M).tar.gz" -C "$HOME" projects
echo "پشتیبان ساخته شد: $(du -h "$dest"/* | tail -1)"
:::

**۲) مانیتور دیسک — اگر پر شد خبر بده:**

::: term
#!/bin/bash
# diskalert.sh — استفاده ریشه را چک کن
usage=$(df / | tail -1 | awk '{print $5}' | tr -d '%')
if [ "$usage" -gt 85 ]; then
    echo "هشدار: دیسک ${usage}% پر است!"
else
    echo "دیسک سالم است: ${usage}%"
fi
:::

**۳) پاک‌ساز امن تمرین‌گاه** — و یک عادت مهم: اسکریپت‌های خود را در `~/bin` نگه دارید و آن پوشه را به PATH اضافه کنید تا مثل دستورهای اصلی، از هر جا اجرا شوند: `echo $PATH` را ببینید، بعد: `mkdir -p ~/bin && cp backup.sh ~/bin/` و از این به بعد فقط `backup.sh` تایپ کنید!

::: warn | قبل از اجرای هر اسکریپت واقعی
یک بار `bash -n script.sh` را اجرا کنید — فقط خطاهای نحوی را چک می‌کند و چیزی اجرا نمی‌شود. برای اسکریپت‌های حذف/تغییر، اول روی داده آزمایشی امتحان کنید و مسیرها را مطلق و دقیق بنویسید. اسکریپت اشتباه، فقط سریع‌تر از دست اشتباه می‌رود!
:::

::: exercise | تمرین فصل ۱۲
اسکریپت `myday.sh` بسازید که: (۱) با `$1` نام شهر بگیرد، (۲) ساعت و تاریخ امروز را چاپ کند، (۳) فضای دیسک و تعداد پروسه‌های فعلی را گزارش کند، (۴) اگر دیسک بالای ۸۰٪ بود هشدار بدهد. با `bash -n` چک، اجرایی کنید و سه بار با آرگومان‌های مختلف اجرا کنید. این اولین ابزار خودساخته‌ی شماست — در فصل ۱۴ به برنامه ۹۰ روزه اضافه‌اش می‌کنیم.
:::

::: key | جمع‌بندی فصل ۱۲
- شی‌بنگ + بنویس + chmod +x + اجرا؛ کاری که دو بار شد، بار سوم اسکریپت است.
- `$1` آرگومان، `read -p` پرسش، `$(دستور)` جایگزینی — مثلث داده در اسکریپت.
- if با براکت و فاصله‌های اجباری؛ for روی لیست‌ها؛ متغیرها همیشه داخل گیومه.
- بکاپ با tar، مانیتور با df+awk، PATH و ~/bin برای ابزار شخصی — جعبه‌ابزار شما شکل گرفت.
:::
