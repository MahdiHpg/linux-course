## ۱۳-۱ | چرا لینوکس برای کدنویسی؟

سه دلیل که توسعه‌دهنده‌ها به لینوکس می‌آیند: **هم‌خوانی با سرور** (کدی که روی لینوکس می‌سازید، دقیقاً در محیطی مثل سرور اجرا می‌شود — «روی سیستم من کار می‌کرد» تمام است)، **مدیر بسته برای همه‌چیز** (زبان‌ها و ابزارها با apt یا مدیر بسته‌ی خود زبان نصب می‌شوند)، و **ابزارهای خط فرمان** که اتوماسیون را به استاندارد تبدیل می‌کنند. و یادتان باشد: WSL2 یعنی ویندوزی‌ها هم همین مزایا را دارند.

## ۱۳-۲ | گیت؛ دفترچه زمان کد

گیت تاریخچه‌ی پروژه را نگه می‌دارد و با تیم‌ها (و با آینده‌ی خودتان!) آشتی می‌دهد. نصب و شروع:

::: term
$ sudo apt install -y git
$ git config --global user.name "Mehdi"
$ git config --global user.email "mehdi@example.com"
$ mkdir ~/projects/hello && cd ~/projects/hello
$ git init                        # تولد مخزن
$ code app.py                     # یک فایل بسازید
$ git status                      # چه خبر؟ (فایل قرمز = جدید)
$ git add app.py                  # روی صحنه ببر
$ git commit -m "اولین نسخه"      # عکس تاریخ‌دار از پروژه
$ git log --oneline               # تاریخچه کوتاه
:::

چرخه‌ی روزانه‌ی گیت همین چهار مرحله است: `status` ← کار ← `add` ← `commit`. اتصال به گیت‌هاب هم دو قدم است: کلید ssh (فصل ۱۱) را در تنظیمات گیت‌هاب ثبت کنید و بعد `git clone git@github.com:user/repo.git` یا برای پروژه‌ی خودتان `git remote add origin ...` و `git push -u origin main`.

::: tip | سه دستور نجات در گیت
`git diff` چی تغییر کرده؟ | `git restore file` این فایل را به آخرین commit برگردان | `git log --oneline --graph` تاریخچه‌ی شاخه‌ها با شکل. و قانون طلایی: **کامیت‌های کوچک و پرتعداد** بهتر از کامیت‌های غول‌آسا هستند — هر قدمِ منطقی، یک عکس.
:::

## ۱۳-۳ | پایتون، نود و محیط VS Code

**VS Code** را نصب کنید (از سایت رسمی فایل `.deb` یا App Center) و پسوند فارسی/پایتون/داکرش را هم اضافه کنید. یکپارچگی با ترمینال، مهم‌ترین ویژگی‌اش است: در هر پوشه پروژه، `code .` کل همان پوشه را با ترمینالِ داخلی باز می‌کند.

**پایتون** در اوبونتوی ۲۶.۰۴ از قبل هست (`python3 --version`). قانون طلایی پایتون: هر پروژه یک **محیط مجازی** تا کتابخانه‌های پروژه‌ها با هم قاطی نشوند:

::: term
$ python3 -m venv ~/projects/hello/.venv
$ source ~/projects/hello/.venv/bin/activate    # ورود به محیط
(.venv) $ pip install requests                   # نصب فقط برای این پروژه
(.venv) $ python -c "import requests; print('OK')"
$ deactivate                                     # خروج
:::

**نود (Node.js)** را با **nvm** نصب کنید تا بتوانید چند نسخه داشته باشید (استاندارد صنعت):

::: term
$ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
$ source ~/.bashrc
$ nvm install --lts          # آخرین نسخه LTS نود
$ node -v && npm -v
$ npm create vite@latest my-app   # یک پروژه مدرن در ده ثانیه
:::

## ۱۳-۴ | داکر؛ کد را جعبه‌ای بفرست

مشکل کلاسیک: «روی سیستم من کار می‌کرد». داکر پاسخ است: برنامه + همه‌ی وابستگی‌هایش داخل یک **کانتینر** بسته می‌شود که همه‌جا یکسان اجرا می‌شود. همین امروز لمسش کنید:

::: term
$ sudo apt install -y docker.io
$ sudo usermod -aG docker $USER && newgrp docker   # بدون sudo
$ docker run hello-world        # اولین کانتینر: پیام خوش‌آمد
$ docker run -d -p 8080:80 nginx   # یک وب‌سرور واقعی!
$ curl http://localhost:8080    # جواب nginx را ببینید
$ docker ps                     # کانتینرهای در حال اجرا
$ docker stop $(docker ps -q)
:::

آن `-p 8080:80` یعنی «پورت ۸۰ کانتینر را روی ۸۰۸۰ سیستم من باز کن» — و یک nginx واقعی روی سیستم شما بالا آمد بدون هیچ نصب و تنظیمی. همین سادگی است که داکر را استاندارد صنعت کرده؛ مسیر عمیق‌ترش (dockerfile، compose) بعد از این دوره راه روشنی دارد.

::: exercise | تمرین فصل ۱۳
یک پروژه واقعی از صفر: (۱) پوشه `~/projects/linux-final` و `git init`. (۲) محیط مجازی پایتون بسازید و یک اسکریپت از فصل ۱۲ را داخلش کپی و اجرا کنید. (۳) همه‌چیز را add/commit کنید و `git log` را ببینید. (۴) اگر ویندوزی‌اید، همین پروژه را در WSL تکرار کنید و تفاوت سرعت را حس کنید. (۵) با داکر یک nginx روی پورت ۸۰۸۱ بالا بیاورید و از مرورگر بازش کنید.
:::

::: key | جمع‌بندی فصل ۱۳
- گیت با چهار مرحله: status ← add ← commit ← push؛ کلید ssh برای گیت‌هاب.
- پایتون با venv برای هر پروژه؛ نود با nvm؛ `code .` پل ترمینال و VS Code.
- داکر یعنی «بسته‌ی اجرای یکسان»؛ run با -p پورت را باز می‌کند و چند ثانیه بعد وب‌سرور دارید.
- WSL2 همه‌ی این‌ها را برای ویندوزی‌ها هم می‌آورد — بهانه نمانده!
:::
